## 课程简介

本课程是一份技术指南，讲解如何用 AI 改造软件开发生命周期（SDLC）：当智能体（agent）编写大部分代码后，规划、评审、测试和部署成为新的瓶颈——本手册给出在 Plan / Design / Build / Test / Deploy / Maintain 六个阶段将 Claude 集成进 SDLC 各环节的最佳实践。
