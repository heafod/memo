# 原型控件 → shadcn 组件映射表（001-plan PR-8）

范围：`prototype/` 的全部 UI 控件（`src/styles/components.css`、`overlays.css`、`states.css`、`shell.css`、`panels.css` 中的控件类，及 `src/ui/`、`src/overlays/`、`src/components/` 的渲染函数）。原型是只读转换源，交互行为以原型为真源（`intent/001-design.md`），视觉以 `intent/design/001/` 设计稿为准。

- **状态**：`已引入` = 组件源码已由 shadcn CLI 进仓 `src/components/ui/`；`待引入` = 由首个用到它的批次执行 `npx shadcn@latest add <组件> -y` 进仓，并把本表该行改为 `已引入`（同批提交）。
- **非 shadcn**：shadcn 无对应件时写明实现方式（组合现有组件、Tailwind 直写、或第三方库），同样标注状态。
- **样式**：一律用 `src/index.css` 映射后的语义类（`bg-primary`、`text-muted-foreground`、`border-border`…），不另立色值；token 权威源 `prototype/src/styles/tokens.css` 不改。
- **shadcn 配置**：`components.json`（style `radix-nova`、base Radix、图标 lucide）；CLI 4.22.1 非交互执行 `init -t vite -b radix -p nova -y` 与 `add -y`。
