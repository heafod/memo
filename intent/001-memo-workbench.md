# 意图：清爽宁静的项目管理工作台

作者：tony（产品发起人）。状态：草稿。

## 问题

常见项目管理工具界面嘈杂、信息密度过高，个人开发者与小型团队在多项目之间切换时缺乏一个结构清晰、无干扰的工作台；现有工具的视图（看板 / 列表 / 日历 / 时间线）彼此割裂，无法围绕同一份项目数据自由切换。

## 提议的结果

一个名为 Memo 的项目管理工作台，具备：

- 首页仪表盘：汇总今日待办与整体进展
- 收件箱与「我的任务」：个人视角的任务归集
- 项目多视图：看板、列表、表格、日历、时间线、文件视图共享同一数据
- 成员、团队、动态与设置：协作所需的组织信息

整体气质「清爽宁静、结构清晰」，界面噪音最小化。

## 受影响的用户和系统

- 用户：个人开发者与小型团队
- 系统：`src/frontend/` 前端应用（原生 JavaScript ES 模块 + CSS，Vite 打包，无 UI 框架、无运行时依赖）

## 约束

- 不引入 UI 框架与运行时依赖，保持原生 ES 模块 + CSS 架构
- Node.js 18+（`.nvmrc` 固定 22）
- 代码检查与格式化遵循现有 ESLint / Prettier 配置，CI 保持绿
- 前端原型先行（种子数据演示）；数据以 localStorage 临时存储，产品要求最终交付后端与持久化数据库（如 MySQL、PostgreSQL），另行立项
